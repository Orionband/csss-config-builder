CSSS Builder Documentation

1. Lab Workflow

  • Import the Packet Tracer file (.pka). Must contain the Answer Network.
  • Use the Tree View to find configurations.
  • Click + Add to create a grading check.

2. Check Types

Use the dropdown in the check card to select logic. "Not" versions invert the check (Fail if found).

  • ConfigMatch / Not: Exact string match (e.g., hostname R1).
  • ConfigRegex / Not: Pattern match (e.g., ^enable secret 5 .*).
  • XmlMatch / Not: Hardware attributes (e.g., Model).
  • XmlRegex / Not: Pattern match for XML values.

3. Quiz Workflow

  • Create quizzes in the Quiz Builder tab.
  • Text Questions: Support Regex logic.
  • Radio: Single choice only.

4. Export

Copy the text from the bottom output panel into your lab.conf or quiz.conf.

Anti-Cheat

Ensure you delete the answer network from the PKA file before giving it to students.
