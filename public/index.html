How to Use CSSS Builder

Quick Start

  1. Click Open .pka in the top-right to load your Packet Tracer activity file.
  2. The Tree View (left pane) will populate with your devices and their configurations.
  3. Browse to any config line, then click + Add to create a grading check for it.
  4. The generated lab.conf output appears in the bottom-right panel. Copy it to your server.
  5. Use PKA Settings to configure locks and timers, then click Download Modified PKA for student distribution.

Lab Builder

  • Tree View: Expands each device's parsed configuration. Click any node to inspect its value. Click + Add to add it as a grading check in the right pane.
  • Show Differences Only: Hides elements that are identical between the Initial and Answer networks. Use this to quickly find what was configured in the answer key.
  • Raw XML: Shows the full unprocessed XML from the PKA with line numbers aligned to each source line (long lines scroll horizontally instead of wrapping). Click the <> icon on any tree node to jump to that value in Raw XML—the view scrolls to the match and highlights it without reloading the whole file. Use ← Back to Tree to return.
  • Comp Start / Comp End: Optional competition window for when students may submit. Use the date and time pickers in the lab settings panel; they always represent UTC, not your PC's local timezone or the server's timezone. The green readout below each picker shows the exact comp_start / comp_end string written to lab.conf (e.g. 2026-04-02T10:00:00Z). Click × to clear a window. Leave both empty for no time restriction.
  • Lab Selector: Manage multiple labs in a single session. Use + Add Lab to create a new one and configure its metadata (ID, title, limits, etc.).
  • Manual Check: Add a check without selecting from the tree. Useful when you know the config path already.

Check Types

  • ConfigMatch: Exact string match against the device running config.
  • ConfigRegex: Regex pattern match against the running config.
  • XmlMatch: Exact match on a hardware/topology XML attribute.
  • XmlRegex: Regex match on an XML attribute value.
  • Type5Match: Validates a Cisco MD5 password hash without needing the salt. Use Device mode for enable secret, User mode for username secret.

Appending Not to any check type (e.g., ConfigMatchNot) inverts the result. The check passes only if the condition is not found.

PKA Settings & Export

  • Timer Mode: Set to Countdown and specify a time limit to enforce a deadline directly in the Packet Tracer client.
  • Lockable Features: Restrict access to Delete Tool, Check Results, CLI access, and other features.
  • Replace: Replaces the answer network with a blank one as well as deleting checked items by the activity wizard.
  • Download Modified PKA: Exports the PKA with all settings applied.

Lab Checks & Advanced Conditions

A check evaluates conditions in a hierarchy. Click + Add Condition inside a check to add more rules:

  • Fail: If *any* Fail condition matches, the entire check fails and awards 0 points. Useful for penalizing insecure setups (like open Telnet).
  • PassOverride: If *any* PassOverride condition matches, the check immediately passes. Useful when there are multiple valid ways to configure something.
  • Pass: If no Fail or PassOverride conditions trigger, *all* Pass conditions must match for the check to pass.

Penalties: You can set negative points (e.g. -5) to penalize students for misconfigurations. The total lab score will bottom out at 0.

Quiz Builder

  • Switch to Quiz Builder in the top nav. Click + Create to start a new quiz.
  • Click + Add Question to insert questions. Supported types: Text (with optional Regex matching), Multiple Choice, and Matching (drag-and-drop).
  • Comp Start / Comp End: Same UTC date/time pickers as in Lab Builder—values are always stored and exported in UTC for quiz.conf.
  • To attach an image or PKA file to a question, use the Exhibit option on that question row.
  • Copy the quiz.conf output to your server when done.
