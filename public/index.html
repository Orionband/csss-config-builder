How to use the nuilder

1. Import Packet Tracer Activity

Upload the packet tracer activity. This must contain the answer network.

2. Build Configuration

  • Browse: Use the tree on the left to explore devices, IOS configs, and hardware attributes.
  • Search: Type in the search bar to find specific things.
  • Add Checks: Click the + Add button next to any item to create a grading check.
  • Edit: Adjust points and messages in the right panel.

3. Export

Click Copy Config and paste the result into your server's lab.conf file.

To prevent cheating
  1. Open activity wizard and then answer network.
  2. Import the starting or blank network
  3. Save the file
  4. Ensure there are also no other checks, if so, remove them.
